Start with a scan.

Install from this project's GitHub repository using pipx. You will need Python 3.9 or later and Git.

Install from source

pipx install git+https://github.com/momenbasel/AgentGuard.git
pipx ensurepath

Open a new terminal after updating PATH, then check agentguard --version. The repository is the installation source for this project.

Inspect a command

agentguard scan "npm install lodasx"

The CLI analyzes the quoted command. It does not execute it. Exit code 2 indicates a HIGH or CRITICAL finding.

Local checks. More context when connected.

Combine package-name and command checks with registry information and security advisories.

Local

Catch suspicious names and commands

  • Typosquatting: compare names and scopes with known npm and PyPI packages, including lookalike characters.
  • Blocklists: match package names against the bundled list and your additions.
  • Shell patterns: flag piped remote scripts, elevated installs, and other risky patterns.
Network

Check the package's context

Inspect registry metadata, repository status, and OSV advisories. Results depend on service availability and the information those services provide.

Optional

Add VirusTotal checks

Enable package hash and URL lookups with your own API key. URL submissions may send the scanned URL to VirusTotal.

One command, an explained result.

In the Claude Code hook, inspection happens before a Bash tool call executes.

  1. Parse the command

    Extract recognized package installs, repository URLs, and download actions.

  2. Run enabled checks

    Check package names, shell patterns, and available registry or advisory data.

  3. Return findings

    HIGH and CRITICAL findings block in the hook. Other findings are reported as warnings or information.

Choose where you check.

Use automatic inspection in a supported hook, or request a scan explicitly from your tools.

Claude Code hook

Install a PreToolUse hook for Bash commands. The global option modifies your user settings.

agentguard install --global

Run without --global for project settings. The hook requires agentguard on PATH.

CLI scanner

Inspect commands on demand, or use JSON findings in your own workflow.

agentguard scan --json "pip install reqeusts"

MCP server

Expose scanning tools to an MCP client. The client must request a scan; MCP access alone does not intercept its shell commands.

agentguard mcp

Know what is being checked.

The parser recognizes commands from npm, pnpm, yarn, bun, pip, uv, Composer, Go, Cargo, RubyGems, Homebrew, Git, curl, and wget. Check depth varies by ecosystem.

Does it protect every coding assistant automatically?

The included installer adds a Claude Code Bash hook. Other assistants can use the CLI or MCP server, but require their own integration to enforce a scan before execution.

Does it inspect every file in a package?

No. AgentGuard uses name checks, known-package lists, shell patterns, metadata, and optional external services. It is a screening layer, not a sandbox or complete malware analysis system.

What happens if a network check fails?

Network availability affects coverage. A failed registry or repository lookup does not itself block the command. Use verbose output to inspect reported lookup failures.

Can I change what gets reported?

Use agentguard config init to create configuration, then configure enabled checks and package allowlists or blocklists. Review exceptions carefully because allowlisted packages skip package checks.
